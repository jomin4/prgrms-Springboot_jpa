# 6~7강 — 첫 엔티티(Post) & ddl-auto

## 🧠 머릿속 그림
```
Post.java (@Entity)   ──Hibernate 번역──▶   DB 테이블 post
  @Id int id                                id INT PK AUTO_INCREMENT
  @GeneratedValue(IDENTITY)
  String title                              title VARCHAR(255)
  ▲ ddl-auto: update 가 이 자동 생성을 켜는 스위치
```

## 📌 핵심 내용
- **Post 엔티티** (`domain/post/post/entity/Post.java`): `@Entity`, `@Id`, `@GeneratedValue(strategy=IDENTITY)`, 필드 `int id`·`String title`. Lombok `@Getter/@Setter`.
- **매핑 규칙**: 클래스→테이블, 필드→컬럼, `int`→integer, `String`→varchar(255), `@Id`→PK, `@GeneratedValue(IDENTITY)`→auto_increment.
- **application.yaml `spring.jpa`**:
  - `show-sql: true` → 실행 SQL 콘솔 출력.
  - `hibernate.ddl-auto`: 6강 `create`(매번 drop 후 생성) → 7강 `update`(없으면 생성/변경만, 데이터 유지).
- ddl-auto 옵션: `create`(재생성) / `update`(증분) / `none`(안함, 운영용).

## 🔍 디버깅 정리 (실제 값)
`./gradlew bootRun` (db_dev 초기화 후) 콘솔:
```
Hibernate: create table post (id integer generated by default as identity, title varchar(255), primary key (id))
```
- `create table` 한 줄도 직접 안 썼는데 엔티티만 보고 JPA가 자동 생성 → 1강 "객체→SQL 번역" 실증.
- `int id` → `id integer ... identity`, `String title` → `title varchar(255)`, `@Id` → `primary key (id)` 로 1:1 대응 확인.
